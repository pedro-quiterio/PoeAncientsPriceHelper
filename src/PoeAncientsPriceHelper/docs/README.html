Poe Ancients Price Helper

A screen overlay for Path of Exile 2 that reads your currency-exchange list and shows live poe.ninja prices right next to each item.

What it does

Open a currency / reward list panel in game, and the tool reads the item names on screen and draws the current market price next to each one — so you never have to alt-tab to poe.ninja to know what a stack is worth.

Getting started

  1. Run PoeAncientsPriceHelper-win-Setup.exe from the Releases page. It installs per-user (no admin, no .NET required) and keeps itself up to date after that.
  2. The first time, Windows SmartScreen may say “Windows protected your PC” because the app isn’t code-signed. Click More info → Run anyway. The first launch also downloads a few currency icons, so give it a second.

Choose your league

Use the League dropdown at the top of the window to match the league you’re playing. It includes both the standard (softcore) league and its Hardcore variant — e.g. Runes of Aldur and HC Runes of Aldur. Pick the right one so prices come from the matching poe.ninja economy. Switching re-fetches prices automatically, and your choice is remembered next time.

Hardcore and softcore are priced in different currencies (softcore in Divine Orbs, hardcore in Exalted Orbs). The overlay handles this for you and shows the correct currency icon per item — just make sure the dropdown matches your league.

Step 1 — Calibrate the panel

Calibration tells the app where on your screen the in-game list appears. You only need to do this once (and again if you change resolution or move the panel).

  1. Click Calibrate Region in the app (or press F4 any time).
  2. Your screen dims. Drag a box around the in-game item list panel.
  3. Press ENTER to confirm (or ESC to cancel and try again).

Step 2 — See prices

Click Start, then open a list panel in game. Prices appear to the right of each row. For stacks, the line shows the total followed by the per-item price, e.g. 2 (0.5 each).

Uncut gems

Uncut skill, spirit and support gems are now priced too. Because a gem’s value depends on its level, the tool matches the exact gem type and level shown on the item — an Uncut Spirit Gem (Level 19) is priced as a level-19 spirit gem, not a level-18 one.

If a gem’s type or level can’t be read cleanly for a moment (a blurry frame, or the panel still sliding into view), that row briefly shows ? instead of a price — it fills in as soon as it gets a clean read. This is on purpose: neighbouring gem levels can differ several-fold in value, so the tool would rather show nothing than a confidently-wrong price.

Island Rumours (Atlas overlay)

With the Island Rumour helper enabled (in Settings), the app watches the Atlas and, when you open an Uncharted Waters / Island Rumours panel, shows each rumour’s map, mods and rating beside it — read from a community-maintained spreadsheet.

To know when you’re on the Atlas, it looks for the “WORLD” label at the top-centre of the map. This is found automatically by default. If you play in windowed mode or a custom resolution and the rumour overlay never appears, you can point the app at the label yourself:

  1. Open Settings and untick “Auto-detect the Atlas map”.
  2. Open the Atlas in game so the WORLD label is visible.
  3. Click “Set WORLD region…”, then drag a box around the “WORLD” text at the top-centre of the map and press ENTER.
You only need this if auto-detect can’t read the label on your setup. The region is stored in fixed screen coordinates, so re-set it (or switch auto-detect back on) if you move the game window or change resolution.

Update notifications

When the app starts it quietly checks GitHub for a newer release. If one is available, a red “Update available” link appears at the bottom of the window — click it to open the download page. If you’re offline or already up to date, nothing happens and no link is shown.

Hotkeys

KeyAction
F4Recalibrate the panel region
F5 (default)Start / stop scanning — rebindable (see below)
F3Toggle debug boxes (shows the scanned region + per-row boxes)
ESCHide the overlay (also fires when you close the panel)
Ctrl + ClickHide the overlay (the in-game “purchase” gesture)

To use a different Start/Stop key, click Rebind next to Start/Stop key in the app, then press the key you want — it’s saved and takes effect immediately. F3, F4, ESC and Ctrl are reserved (they’re used for the actions above); press ESC to cancel.

Tip: an F-key (or another key you don’t press while typing) makes the best Start/Stop hotkey — it works globally even while the game is focused, so a normal letter would also trigger it while chatting or browsing.

Tips & troubleshooting

  • Prices look slightly off? Market prices come from poe.ninja. The app fetches them when it starts (and when you switch league), then auto-refreshes every 30 minutes in the background. The on-screen overlay itself updates live (a few times per second) as you open panels — so what you see reflects the latest 30-minute fetch.
  • Overlay misaligned? Press F4 and recalibrate — this usually happens after a resolution or UI-scale change.
  • Nothing shows up? Make sure you clicked Start and that the calibrated box actually covers the list panel. F3 shows the scanned region so you can check.
  • Antivirus warning? The app uses a global-hotkey library (uiohook.dll) so F3/ESC/Ctrl+Click work while the game has focus. Some AV flags this generically; it’s required for the hotkeys.
  • Something’s broken? Double-click debug.cmd (see below) to run with diagnostics, then send the log.

Report a bug

Found something wrong, or have a request? Please open an issue on GitHub:

github.com/pedro-quiterio/PoeAncientsPriceHelper/issues

To make a bug easy to fix, include a diagnostics log:

  1. Click the Diagnostics link at the bottom of the app window — it restarts the app with logging on (a console window opens alongside it).
  2. Reproduce the problem (calibrate, open the panel, open the Atlas, press F3, etc.).
  3. Close the app, then click Diagnostics again (now labelled Open logs) to open your data folder.
  4. Attach scan_log.txt (prices) and/or rumour_scan.txt (rumours), plus a screenshot of what you saw, to your GitHub issue.
Debug mode is the same app with extra logging — it’s safe to use normally.
